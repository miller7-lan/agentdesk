| 事项 | 决定 |
|---|---|
| VPS | 两台。**现阶段只开发 VPS2（4 GB 内存 + 2 GB swap）**：主控、四个 CLI、任务容器都在这台。VPS1 的中转服务先不动 |

| 视觉 | 白色为主的玻璃质感，背景带一点流动，**阅读区域优先保证清晰** |
| 多人 | 2～3 人同时开发（基础场景）：任务并行、轮流分配，每个 CLI 同一时间一个进程，共享额度按人统计 |
| 开机动画 | 默认**每次启动 App** 播放；最小化后恢复、从托盘重新打开都不算启动；**双击直接进入** |

|---|---|
| 系统 + Docker | 约 0.4 GB |
| 主控 + Codex App Server | 约 0.4 GB |
