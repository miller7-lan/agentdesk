# 权限

- 首次连接需要核对 SSH 主机指纹。登记构建从发布包携带的信任配置取得主机记录。
- 本机工作区由系统目录选择器授权。预览和 Git 改动读取限定在当前项目，路径穿越与指向工作区外的符号链接会被拒绝。
- 主控按 Bridge 身份校验项目和工作区。项目成员可以查看其他人的任务状态，补丁、产物、日志及应用和取消仅对任务提交者与管理员开放。
- 群聊记住的命令授权要求线程、工具和目录完全相同。可在成员面板清除本群规则。
- 本机桌面控制可从状态栏开启或关闭。macOS 用到桌面操作时，在系统设置中授予对应工具辅助功能权限，截图需要屏幕录制权限。计划模式关闭桌面工具。
- 单聊默认「对话与查看」，直接由所选 AI 处理，不经过组长；需要改动时选择「修改文件」，预览后确认应用。只读对话不要求本机 Git 干净或已有提交。
- Bridge 的工作区可配置 `readRoots`（例如 `{"desktop":"<本机桌面路径>"}`），只开放这些命名目录的列举、读取与搜索。额外目录不提供写入、命令或桌面操作权限；符号链接与路径越界仍被拒绝。
- 单聊任务标记为 `direct`，不会作为组长派遣记录显示在群聊中；群聊派遣记录只读，继续对话应新建单聊。
