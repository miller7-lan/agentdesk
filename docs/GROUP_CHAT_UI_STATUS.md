# 群聊 UI 规范对照

对照 Claude 分支提交 `a96ce09` 的 [群聊设计规范](https://github.com/miller7-lan/agentdesk/blob/a96ce09a8fe4fa0cdffe3b09fdbfb937f485e5b4/docs/GROUP_CHAT_UI.md)、[交互原型](https://github.com/miller7-lan/agentdesk/blob/a96ce09a8fe4fa0cdffe3b09fdbfb937f485e5b4/docs/prototype/group-chat.html) 和 [容器云任务方案](https://github.com/miller7-lan/agentdesk/blob/a96ce09a8fe4fa0cdffe3b09fdbfb937f485e5b4/docs/WECHAT_OMC_PLAN.md)。

| 规范范围 | 当前实现 | 依赖或差距 |
|---|---|---|
| 项目导航与会话 | 项目树可搜索、折叠。每个项目可创建任意数量的单聊和最多一个主群，群聊创建状态按项目保存。历史线程保留，Ctrl+Tab 切换最近会话。 | 主控当前按客户端配置绑定工作区。其他真实工作区的主控绑定、项目创建、未读计数、微信标记和其他 CLI 的独立单聊需要对应接口及会话存储。 |
| 派活及消息路由 | 默认自动协作。发给 Codex、Claude Code、Grok Build 或已配置的 Gemini 时走指定 CLI。支持指定模型、输入 `@` 选择成员及 `/` 命令建议。 | 组长对应当前调度器，调度器使用 Codex 规划。全员广播、Antigravity 执行、OMC 和群级权限设置缺少主控接口。 |
| 群聊时间线 | 用户发言、单任务卡片、成员输出摘要、待审补丁和待核对操作。支持按成员、与我相关、待处理筛选。步骤输出在任务详情折叠。 | 自由发言、交叉审查引用、待回答的问题和微信来源标签需要结构化消息事件。 |
| 审批 | 群聊展示本机补丁审核和在途操作核对。Codex 单聊继续使用原有审批与权限模式。 | 群聊逐次命令审批、群内记住授权和群级权限设置需要主控审批协议。 |
| 成员与头像 | 带标志的 Canvas 头像覆盖顶部成员条、成员页、单聊侧栏、单聊标题和提及列表。群聊与单聊的消息头像均显示静止标志。状态图鉴可检查原型的 12 种状态、道具、悬停和连点反应。支持减少动态效果和后台暂停。 | Antigravity 位于图鉴。群成员的登录、额度和上下文整理状态取决于各 CLI 能否提供事件。Codex 单聊使用现有连接、额度及上下文事件。 |
| 任务与产物 | 任务卡片随轮询更新，右侧调度图显示方案确认、实际分工与各步骤依赖，节点可查看状态、改动路径和步骤输出。任务详情显示耗时，支持刷新、取消、审核应用补丁、核对及重填任务。 | 主控协议提供输出摘要和改动路径。按任务查看完整 Diff、实时日志、产物及完整项目历史需要接口。云端任务与微信 `/ls` 尚未接通。 |
| 状态栏与连接 | 显示主控 SSH／Relay 线路、Codex SSH 和本机桌面状态；有任务活动的 CLI 可直接跳到成员页。 | 容器计数、内存、swap 及每个 CLI 的登录状态依赖云任务服务的遥测。 |
| 命令 | 群聊支持 `/ls`、`/stop #任务编号`、`/routes`、`/avatars`。Codex 单聊保留原命令。 | 规范的 `/duo`、`/team`、群聊 `/compact`、`/review` 与全员广播依赖调度和上下文接口。模型可从群聊输入区选择。 |

头像状态图鉴使用演示状态。生产群聊的状态来自现有主控及 Codex App Server，容器、微信和 CLI 凭据数据仅在相应接口提供时接入。
