# 群聊 UI 规范对照

| 范围 | 当前实现 |
|---|---|
| 项目与会话 | 项目树可搜索、折叠。可新建示例项目或绑定已授权的主控项目。主控 Bridge 可为各项目配置独立工作区。群聊按项目记录已读时间和任务历史。 |
| 调度 | 普通任务经组长规划和确认后分派。支持 `/duo`、`/team`、`/compact`、`/review`、`/chat`、`/broadcast` 和 `@all`。Claude 保留规划、诊断和验收职责。 |
| 消息 | 群聊显示自由发言、引用、派发卡、步骤、问题和事件。任务卡显示提交者、项目、模式、阶段、返工、冲突和验收状态。 |
| 审批 | 当前群可接收所属 Codex 线程通过 App Server 发起的审批和提问。记住的规则按群保存，对线程、工具和目录做精确匹配。 |
| 任务详情 | 可查看调度图、本人任务完整补丁（24 KiB 上限）、步骤日志末尾和产物。其他成员只看到脱敏进度和结论。 |
| 连接与资源 | 状态栏支持主控 SSH / Relay、订阅额度、主机内存、Swap 和容器数据，点击资源进入成员页。 |

`/team` 在 Docker 运行器和 OMC 命令均可用时可调用容器内启动器，其余环境使用普通多步骤计划。容器指标和云端 CLI 行为有待 VPS2 实机验收。项目群审批使用已绑定 Codex App Server 线程，批处理 CLI 的审批需要服务端提供对应交互事件。
